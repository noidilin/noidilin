## English

Dear Hiring Team,

I am applying for the Cloud Developer role on Trend Micro's Vision One XDR team. The role's emphasis on full-cycle cloud feature delivery, cross-team integration, and continuous automation aligns with my work across product engineering and hands-on cloud-native platform development. I am particularly interested in building services that help security analysts investigate complex system activity more effectively.

In Hiraya E-commerce, I designed a cloud-native AWS EKS platform with Terraform and GitOps workflows, then automated full platform deployment and destruction through GitHub Actions, ECR, Argo CD, and Kustomize. In Misegoto, I delivered payment, receipt, and document workflows with typed API handling and built data-flow patterns that made operational tooling easier to maintain and review. Together, these experiences support your need for cloud delivery grounded in clear integration boundaries and maintainable software practices.

I would bring AWS platform practice, automation discipline, and product-facing API integration experience to Trend Micro. I would welcome the opportunity to discuss how I could contribute to the Vision One engineering lifecycle.

Sincerely,
Jia-Long Lin
