## English

Dear Hiring Team,

I am applying for the Cloud Software Developer role on Ubiquiti's Billing team. The role's emphasis on AWS services, maintainable APIs, microservice boundaries, and payment workflows aligns with my hands-on cloud platform work and product-facing integration experience. I am particularly interested in connecting reliable cloud foundations with billing experiences that remain predictable for users and engineering teams.

In Hiraya E-commerce, I built a five-service storefront with gateway, authentication, catalog, order, and user services behind contract-tested API boundaries, supported by a Terraform-managed AWS EKS platform. In Misegoto, I delivered payment, receipt-output, and document-output flows with typed API handling and maintainable data-flow patterns for operational tooling. Together, these experiences support your need for cloud software shaped by explicit service boundaries and careful product integration.

I would bring AWS architecture practice, contract-oriented systems thinking, and direct experience integrating transaction workflows to Ubiquiti. I would welcome the opportunity to discuss how I could contribute to the Billing team's cloud services.

Sincerely,
Jia-Long Lin
