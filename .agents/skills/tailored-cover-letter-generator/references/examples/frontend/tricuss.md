## English

Dear Hiring Team,

I am applying for the Software Engineer (Frontend) role at Tricuss. The role's emphasis on turning complex AI research data into reliable React and TypeScript interfaces aligns with my work as a frontend engineer building B2B workflows and maintainable typed systems. I am particularly interested in helping scientific users navigate data-intensive agent workflows and reports.

In the Misegoto project, I rebuilt a Japanese B2B admin dashboard with Next.js 16 and React 19, implementing advanced tables with filtering, export, batch actions, permission-aware interactions, and typed API handling. In Hiraya E-commerce, I built a five-service storefront behind contract-tested API boundaries and designed its AWS EKS platform with Terraform and GitOps workflows for reproducible rebuilds. Together, these experiences support your need for data-heavy product delivery backed by clear integration boundaries and maintainable engineering foundations.

I would bring product-focused frontend delivery, typed data-flow experience, and complementary systems ownership to Tricuss. I would welcome the opportunity to discuss how I could contribute to the Co-researcher frontend experience.

Sincerely,
Jia-Long Lin
