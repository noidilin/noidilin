## English

Dear Hiring Team,

I am applying for the Frontend Developer role on the UniFi Connect team at Ubiquiti. The role's emphasis on reusable React components, sophisticated visual interactions, and frontend engineering quality aligns with my work as a frontend engineer building maintainable product patterns and typed workflows. I am particularly interested in making complex device-management tasks feel clear and responsive.

In the Misegoto project, I rebuilt a Japanese B2B admin dashboard with reusable UI primitives, responsive layouts, advanced table interactions, and typed API data flows that made operational tooling easier to maintain and review. In Hiraya E-commerce, I automated AWS EKS platform delivery through GitHub Actions, Terraform, and GitOps tooling, while adding AI PR review and agentic documentation updates to keep architecture explanations aligned with implementation changes. Together, these experiences support your need for reusable frontend foundations and disciplined AI-assisted engineering workflows.

I would bring React and TypeScript product delivery, maintainable UI patterns, and complementary delivery-systems ownership to Ubiquiti. I would welcome the opportunity to discuss how I could contribute to reliable, intuitive UniFi Connect experiences.

Sincerely,
Jia-Long Lin
